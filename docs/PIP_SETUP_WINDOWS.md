## Install WSL2 without conda

Run PowerShell as Administrator:

```powershell
wsl --install -d Ubuntu-24.04
```

Restart Windows when requested, then launch Ubuntu and run:

```bash
sudo apt update
sudo apt install -y build-essential git wget python3.10 python3.10-venv python3.10-dev
python3.10 -m venv ~/psc-ml
source ~/psc-ml/bin/activate
python -m pip install --upgrade pip setuptools wheel
```

For NVIDIA GPU support, install the current Windows NVIDIA driver with WSL
support. Do not install a separate Linux NVIDIA driver inside WSL. Verify:

```bash
nvidia-smi
```

Install a PyTorch wheel matching the CUDA runtime supported by that driver. Use
the command generated by the official PyTorch selector; for example, do not
blindly reuse the CPU wheel currently installed on Windows.

## OpenFold in WSL

The Windows checkout is visible at `/mnt/c/Users/ng692/Desktop/external/openfold`.
From Ubuntu:

```bash
source ~/psc-ml/bin/activate
cd /mnt/c/Users/ng692/Desktop/external/openfold
python -m pip install -e .
python -c "import openfold; print('OpenFold import OK')"
```

If the native extension fails to build, use the upstream OpenFold Docker image
or a Linux machine. Do not force-install the OpenFold checkpoint into CHIMERA's
local approximation: the tensor layouts are different.

OpenFold inference also needs its own alignment databases and model parameters.
Follow `openfold.readthedocs.io` and record the exact commit and parameter file
hashes after downloading them.

## RFdiffusion in WSL

RFdiffusion requires its model files and the bundled SE(3)-Transformer code:

```bash
source ~/psc-ml/bin/activate
cd /mnt/c/Users/ng692/Desktop/external/RFdiffusion/env/SE3Transformer
python -m pip install -e .
cd ../..
python -m pip install -e .
python -c "import rfdiffusion; print('RFdiffusion import OK')"
mkdir -p models
wget -O models/Base_ckpt.pt \
  http://files.ipd.uw.edu/pub/RFdiffusion/6f5902ac237024bdd0c176cb93063dc6/Base_ckpt.pt
sha256sum models/Base_ckpt.pt
```

The RFdiffusion checkpoint is consumed by RFdiffusion's own sampler. It is not
a state dict for `chimera.flow_matching.SE3FlowMatching`; use a native adapter
that calls `rfdiffusion.scripts.run_inference` or its sampler API.

## Verify source revisions

Run in WSL:

```bash

git -C /mnt/c/Users/ng692/Desktop/external/RFdiffusion rev-parse HEAD
git -C /mnt/c/Users/ng692/Desktop/external/ProteinMPNN rev-parse HEAD
```

Store those commits, checkpoint URLs, licenses, SHA-256 digests, and verified
parameter counts in a checkpoint manifest before enabling production adapters.

## What is expected to work now

- Native Windows CHIMERA tests and the pure-Python ProteinMPNN utilities.
- OpenFold and RFdiffusion imports in WSL after their upstream dependencies,
  CUDA-compatible PyTorch, databases, and weights are installed.
- Cross-platform adapter code only after testing each native upstream API.

What will not work safely: loading `Base_ckpt.pt`, OpenFold parameters, or
ProteinMPNN weights into the local CHIMERA approximation classes. The adapter
must call each upstream implementation or explicitly convert a verified native
checkpoint.
